## 10차: 저해상도 배경의 비율 보호와 어종별 필터링
- 640×640 기존 민물·연안·먼바다 원본을 720×1280 화면에 비균일하게 늘리지 않고, **uniform cover**로 가로 중심부를 보여 줌. 좌우 크롭이 생길 수 있으므로 지역별 모바일 스크린샷으로 구도 검토 권장.
- 360×640 보물섬 원본은 같은 비율로 720×1280에 표시됨. 네 배경 모두 LINEAR 필터를 사용하여 2배 표시 시 인위적인 네모 픽셀을 완화함.
- 512px 이상 물고기는 축소 시 LINEAR 필터, 256px 물고기·도트 캐릭터·플랫폼은 기존 NEAREST 유지. 이는 **원본 디테일을 추가하는 작업이 아니며**, 저해상도 두 어종(참치·개복치) 재제작 필요성은 변하지 않음.

### 모바일 낚시터 헤더 간섭 보정
- 배경 비율 유지 이후 낚시터 문구와 `← 집으로` 버튼의 실제 캔버스 겹침을 발견. 버튼을 화면 상단 안전 위치(y=8 게임 좌표)로 옮기고 브라우저 테스트가 양쪽 표시 경계를 비교하도록 변경함.
